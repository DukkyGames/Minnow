    Modes Experts Work agents Agent packs Sub-agents Autopilot

    Modes

    Experts

    Personas you pick in the composer. Edit prompts in Prompts; try them in Expert Lab.

    Work agents

    Specialized agents (for example UI Designer): enable flags, context budget, and policies. Prompts and models live in Prompts and Models.

    Agent packs

    Bundled agent definitions you can enable for a workspace or session.

    Sub-agents

    Background workers (explore, shell, research, and more): concurrency, timeouts, and tool policy. Prompts and models live in Prompts and Models.

    Autopilot

    Global defaults for orchestrate boards: execution mode, concurrency, isolation, test retries, heartbeat thresholds, and planner model fallback.
