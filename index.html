    Modes

    General, Build, Plan, Orchestrate, Reef, and Debug — tool policy and mode-specific options. Edit prompts in Prompts.

    Experts

    Personas selected in the composer. Edit prompts in Prompts; open Expert Lab for trials.

    Work agents

    Specialized agents (e.g. UI Designer): enable flags, context budget, and policies. Prompts and models live in Prompts and Models.

    Agent packs

    Bundled agent definitions you can enable for a workspace or session.

    Sub-agents

    Background workers (explore, shell, research, …): concurrency, timeouts, and tool policy. Prompts and models live in Prompts and Models.

    Search

    Web search provider, SearXNG URL, API keys, and the Deep Research fallback chain. Controls web_search and future research runs.

    Deep Research

    Dedicated model binding and IterResearch engine limits (research.json). Empty model uses the active chat model.

    Servers

    Managed local services (SearXNG) under ~/.minnow/servers/. When enabled and running, Search and Deep Research use the managed instance instead of the SearXNG URL in search.json.

    Tools

    Built-in tool permissions, filesystem policy, and browser allowlist. Search provider and API keys are under Search. Server tools need npm start.

    MCP servers

    Model Context Protocol servers under ~/.minnow/mcp/. Tools appear as mcp__… in the loop when npm start is running.

    Start with npm start to load and toggle MCP servers.

    Add MCP server

    Lowercase letters, numbers, hyphens, underscores.

    Language servers

    Diagnostics and completions in the file viewer; agent tools get_lsp_diagnostics and list_lsp_servers. Run npm start; config at ~/.minnow/lsp.json.

    Editor

    Copilot-style ghost text in the file viewer. Tab accepts, Esc dismisses. Requires npm start and a configured provider.

    Skills

    Slash commands and SKILL packs (built-in and user). Toggle which skills the agent can load.

    Webhooks

    Outgoing HMAC-signed webhooks for chat completion, session creation, and scheduler events.

    OAuth

    Google and Microsoft app credentials for Email and Calendar sign-in.

    Voice

    Voice model settings moved to Models → Voice (#/app/models/voice). Device routing remains under Settings → Audio.

    Orchestration

    Orchestrate supervisor: heartbeat, stall resumes, repetition detection, and optional LLM escalation. Replaces legacy selfHealing.* toggles.

    Evals

    Local eval harness — task packs, suite runs, and rubric grading under ~/.minnow/evals/.
