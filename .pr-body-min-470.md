## Summary

Implements epic [MIN-470](https://linear.app/minnowai/issue/MIN-470): trims Minnow's visible v1 surface and adds a Skills Library for installing third-party skill packs.

- **App roster (MIN-471):** Promotes Code to `core`; hides email, experts, bench, compare, and calendar from the dock/menubar/onboarding.
- **App-gated tools (MIN-472):** Binds email/calendar tools with `appId` and filters them from the model tool set and Settings → Tools when apps are hidden.
- **Reef removal (MIN-473):** Fully removes the unused Reef mode and subsystem (~8k lines deleted).
- **Skills Library (MIN-474–477):** Curated 5-pack registry with offline indexes, server install/remove/add-from-URL routes, Matt Pocock unbundled to remote install, and Settings → Integrations → Skills Library UI.
