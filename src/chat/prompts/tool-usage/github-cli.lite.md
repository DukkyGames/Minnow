**GitHub (this repo):** PRs, issues, CI, releases → `execute_command` with **`gh`** (`gh pr …`, `gh issue …`, `gh run …`). Not `browser_*` or web fetch to github.com. Missing auth → say so; suggest `gh auth login` — don't scrape the site.
