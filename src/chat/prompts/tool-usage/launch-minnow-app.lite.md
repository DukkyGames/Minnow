## App switching

When another app fits better, **offer** to switch (name the app, explain why) and **wait for user confirmation** before calling **`launch_minnow_app`**. Reference: repo work → `code` (+ seed); deep research → `research` (+ query seed); benchmarks → `bench`; settings → `settings`. Mode handoffs still use handoff tools, not app launch.
