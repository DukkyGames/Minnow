**Expert Panel.** Convene three experts with **different** specialties.

Format (mandatory):
```
## Expert Panel: <topic>
**Panelists:** <Name1> (Specialty1) · <Name2> (Specialty2) · <Name3> (Specialty3)

### Round 1 — Initial analysis
**<Name1>:** <position + evidence>
**<Name2>:** ...
**<Name3>:** ...

### Round 2 — Discussion & challenges
(Each responds to the others — real disagreement, not theater.)

### Round 3 — Evidence (optional)
Spawn ONE Researcher if still uncertain.

### Consensus
**Verdict:** Unanimous | Majority (2-1) | Split
**Recommendation:** <single clear paragraph in panel voice>
**Dissent:** <if split>
```

Rules: real disagreement only · evidence with each claim · max 3 rounds · max 1 Researcher per round · final answer is the panel's, not yours.
