# MIN-189 Investigation

## Verification Status

**Confirmed — bug is valid.**

`npm start` defaults to launching the Electron desktop shell, but a standard install path does not reliably ensure the `electron` package (and its downloaded binary) is present. Users can hit `Electron binary not found. Run npm install.` and currently need a manual `npm install electron` to recover.

---

## Root Cause

Three gaps combine:

1. **Dependency classification mismatch** — `electron` is in `devDependencies`, but it is required for the default developer workflow (`npm start` → `spawnElectronShell`). Installs with `NODE_ENV=production` or `npm install --omit=dev` skip it entirely.

2. **`postinstall` does not cover Electron** — the only postinstall hook syncs Impeccable:

```17:17:package.json
    "postinstall": "node scripts/sync-impeccable-skill.mjs",
```

3. **Electron 42+ lazy binary install** — the `electron` package no longer ships a `postinstall` script. The ~150MB binary is downloaded on first CLI/`require('electron')` via `install.js`, not during `npm install`. The package shim (`.bin/electron`) can exist while the binary is not yet present.

`spawn-electron.mjs` only checks for the `.bin` shim:

```56:59:scripts/spawn-electron.mjs
  const electronBin = electronBinaryPath();
  if (!fs.existsSync(electronBin)) {
    throw new Error('Electron binary not found. Run npm install.');
  }
```

If the package was never installed (production/omit-dev install, or stale `node_modules` after pulling Electron changes), this fails. `server.js` catches the error and falls back to the system browser, which breaks preview/browser tools that expect the desktop shell.

## Proposed Fix

### 1. Move `electron` to `dependencies` (primary fix)

Since `npm start` depends on Electron by default, treat it as a runtime dependency, not a dev-only packaging tool. Keep `electron-builder`, `concurrently`, `cross-env`, and `wait-on` in `devDependencies`.

### 2. Add `scripts/ensure-electron.mjs` and chain it in postinstall

```json
"postinstall": "node scripts/sync-impeccable-skill.mjs && node scripts/ensure-electron.mjs"
```

`ensure-electron.mjs` should:

- Exit early when `MINNOW_SKIP_ELECTRON=1` or `MINNOW_HEADLESS=1` (CI/headless).
- If `node_modules/electron/install.js` exists, run it to **eagerly download** the binary during install.
- If the package is missing, emit a clear warning: `npm install electron` or `npm install --include=dev`.

### 3. Improve the spawn error message

In `spawn-electron.mjs`, change the error to something actionable:

> `Electron not installed. Run: npm install` (or `npm install electron` if using production-only installs).

### 4. Docs

Update `README.md`, `AGENTS.md`, and `documentation/context.md` to note that Electron is installed automatically via `npm install`, with `MINNOW_BROWSER=1` as the opt-out.

### 5. Optional: Node engines

Add `"engines": { "node": ">=22.12.0" }` to Minnow `package.json` (or pin Electron to a version compatible with Node 20) to align with `electron@42` requirements.

**Files to touch:** `package.json`, `package-lock.json`, `scripts/ensure-electron.mjs` (new), `scripts/spawn-electron.mjs`, `README.md`, `AGENTS.md`, `documentation/context.md`.

## Test Plan

1. **Fresh full install** — `rm -rf node_modules && npm install`  
   - Assert `node_modules/.bin/electron` exists  
   - Assert `node_modules/electron/dist/electron.exe` (or platform equivalent) exists **before** `npm start`  
   - Run `npm start`; Electron window opens (no manual `npm install electron`)

2. **Production-style install** — `rm -rf node_modules && NODE_ENV=production npm install`  
   - After fix, `electron` should still be present (moved to `dependencies`)

3. **Skip flag** — `MINNOW_SKIP_ELECTRON=1 npm install` completes without downloading Electron binary

4. **Stale upgrade simulation** — delete only `node_modules/electron`, run `npm install`; postinstall restores package + binary

5. **Fallback path** — with Electron removed and skip flag set, `npm start` falls back to system browser with a clear log message

6. **Regression** — `npm test` (existing `test/electron/*.test.mjs`); `npm run electron:build` still compiles main process
