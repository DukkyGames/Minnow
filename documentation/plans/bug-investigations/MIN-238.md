# MIN-238 — Last command broken

**Linear:** MIN-238  
**Status:** Fixed

## Symptom

Pressing ArrowUp to recall the last command works on the first terminal row, but on later rows the recalled text appears on a line showing `[0[I[0[I` instead of the shell prompt.

## Root cause

`handleHistoryKeys` in `src/ui/terminal-xterm.ts` rewrote history locally via `term.write('\r\x1b[K')`. That only clears the current xterm row from column 0 and does not sync with the PTY shell. After command output (cursor on a later row, prompt with ANSI escapes), local CSI sequences corrupt the display and leave the shell input buffer out of sync.

## Fix

Route history recall through the PTY:

1. Backspace over `lineBuffer.length` characters to clear typed input on the shell.
2. Send the recalled command as PTY input so the shell redraws prompt + text.
3. Update `lineBuffer` to match.

Pure helpers live in `src/ui/terminal-history-nav.ts`; tests in `test/ui/terminal-history-nav.test.mts`.
