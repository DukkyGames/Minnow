# Minnow v0.0.1 — Open beta

First public preview of Minnow: a free, AGPL local-first AI workspace for chat, code, research, orchestration, and memory on the models you already run (LM Studio, Ollama, llama.cpp, or any OpenAI-compatible API).

**This is a beta.** Expect rough edges. Feedback and bug reports are welcome on [GitHub Issues](https://github.com/HenriGrimm/Minnow/issues).

## Highlights

- **Seven core apps** — Code (with chat), Research, Models, Brain, Issues, Scheduler, and Settings.
- **Orchestrator boards** — Turn a plan into a kanban line with Builder/Tester agents and isolated git worktrees.
- **Super Plan** — Interview → spec → research → reviewed plan before code changes.
- **114 built-in tools** (106 in default builds), sub-agents, work agents, MCP, and per-tool permissions.
- **Privacy by default** — No Minnow account, no telemetry; data under `~/.minnow`; loopback-only server until you opt into LAN access.

## Install (Windows)

1. Download **Minnow-Setup-0.0.1.exe** from the assets below (attached when the release is published).
2. If SmartScreen warns about an unsigned build, choose **More info** → **Run anyway** (one-time for the first manual install).
3. On first launch, complete the setup wizard or connect a model from **Settings**.

## Install (Linux)

1. Download **Minnow-0.0.1-x86_64.AppImage** from the release assets.
2. Make it executable: `chmod +x Minnow-0.0.1-x86_64.AppImage`
3. Run it (AppImage; no system package manager required). Tray integration needs AppIndicator/StatusNotifier (common on KDE; GNOME may need an extension).

macOS `.dmg` / `.zip` are documented in the [manual](https://github.com/HenriGrimm/Minnow/wiki). You can also [build from source](#build-from-source) on any platform.

## Updates

Packaged installs check [GitHub Releases](https://github.com/HenriGrimm/Minnow/releases) for `latest.yml`. This release is marked **pre-release** so only users on the **Beta** update channel receive it until you publish a stable build.

## Build from source

```bash
git clone https://github.com/HenriGrimm/Minnow.git
cd Minnow
npm install
npm start
```

See [Setup from source](https://github.com/HenriGrimm/Minnow/wiki/Setup-from-source) on the wiki.
