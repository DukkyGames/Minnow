# Minnow v0.0.2 — Open beta

Second open-beta build focused on the **Code** editor, **Brain** code map, **LSP**, and **local models** on Apple Silicon. Feedback and bug reports are welcome on [GitHub Issues](https://github.com/HenriGrimm/Minnow/issues).

## Highlights

- **Code map follows your workspace** — Brain code index and repo map injection respect the active workspace root instead of a stale global path.
- **Packaged LSP works** — Node-based language servers (TypeScript, Pyright, YAML, and others) start correctly inside the Electron app on Windows, Linux, and macOS.
- **Go (`gopls`)** — Install path uses `go install` with the correct upstream versioning; Go must be on `PATH`.
- **Intent mode** — Restored visible line styling, idle auto-proposals, and correct reindent/cursor placement when accepting suggestions.
- **MLX on Apple Silicon** — Optional `mlx-lm` runtime and Hugging Face catalog search for MLX-quantized models (macOS only).
- **My Models** — Fixed provider binding for Minnow Library / hosted serves (MIN-545).

## Install (Windows)

1. Download **Minnow-Setup-0.0.2.exe** from the [v0.0.2 release assets](https://github.com/HenriGrimm/Minnow/releases/tag/v0.0.2).
2. If SmartScreen warns about an unsigned build, choose **More info** → **Run anyway** (one-time for the first manual install).
3. On first launch, complete the setup wizard or connect a model from **Settings**.

## Install (Linux)

1. Download **Minnow-0.0.2-x86_64.AppImage** from the release assets.
2. Make it executable: `chmod +x Minnow-0.0.2-x86_64.AppImage`
3. Run it (AppImage; no system package manager required). Tray integration needs AppIndicator/StatusNotifier (common on KDE; GNOME may need an extension).

macOS builds for this tag may ship in a follow-up asset drop; you can always [build from source](#build-from-source).

## Updates

Packaged installs check [GitHub Releases](https://github.com/HenriGrimm/Minnow/releases) for `latest.yml` (Windows) or `latest-linux.yml` (Linux AppImage). Attach those feed files when publishing the release or in-app update checks will not see the new build.

## Fixes and changes (since v0.0.1)

### Code editor and Brain

- **Code map / Brain code index** — API and UI pass the active `workspaceRoot` so repo maps, index stats, and injection target the correct folder (#775 follow-up, Brain Code API).
- **Intent mode** — Restored CSS for pending/resolved intent lines; idle proposals work again without enabling a hidden setting; line-leave resolve and accept/reindent no longer jump the cursor to EOF (#779).
- **Packaging** — Pre-package cleanup no longer kills generic Electron processes (e.g. Cursor) when building installers.

### Language servers (LSP)

- **Packaged Node servers** — Spawn bundled CLIs with Electron’s Node (`ELECTRON_RUN_AS_NODE`) so paths inside `app.asar` work and macOS Finder launches find a runtime (#768).
- **Go (`gopls`)** — Managed bundle installs via `go install` instead of a broken GitHub release tag; Settings supports install/remove for Go bundles.
- **Bash** — Docs and defaults clarify ShellCheck is required for diagnostics.
- **Workspace config** — Improved LSP workspace configuration resolution for multi-root setups.

### Models and providers

- **MLX (Apple Silicon)** — Managed `mlx-lm` server, Hugging Face search in Models, safer MLX artifact sizing and quantization detection (#780).
- **Minnow Library / My Models** — Correct `minnow-library` provider id for hosted serves; picker and chat bindings stay consistent after load (MIN-545, #778).
- **Kimi / Moonshot** — Strip reasoning fields from replayed messages where the API rejects them.

### Documentation and tooling

- README, `context.md`, third-party notices, and contributor docs aligned with current app counts and behavior (#775).
- **CI / tests** — Flaky grep, capability-probe, and LSP completion timeouts addressed on Windows and Linux runners.
