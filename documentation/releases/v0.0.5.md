# Minnow v0.0.5 — Open beta

Fifth open-beta build focused on **Issues v2**, **local llama.cpp hosting**, **compact Code composer**, **vision and thinking models**, and **agent-loop reliability**. Feedback and bug reports are welcome on [GitHub Issues](https://github.com/HenriGrimm/Minnow/issues).

## Highlights

- **Issues v2 (#892)** — Capture from anywhere (menubar, Alt+C, right-click, drag-and-drop), grouping/rank/triage, WYSIWYG description editor that round-trips markdown, assign-to-agent via Orchestrate, and GitHub sync with explicit conflict resolution.
- **Local llama.cpp like LM Studio (#891)** — Auto-fit context and GPU offload, crash/OOM diagnosis with retry, resumable downloads, split-GGUF shards, and more than one resident serve under LRU + TTL.
- **Compact composer (#915)** — Narrow Code chat columns collapse to mode dropdown, overflow cog, model chip, and context wheel. The cog is a two-page sheet (this-turn settings, then Tools).
- **Qwen3.8 and thinking (#878)** — Catalog Qwen3.8-27B hosting, map composer High to `xhigh`, keep thinking across budget cuts, and parse Qwen-style tool calls from local runtimes.
- **Agent harness floor (#875)** — Stop mid-batch no longer crashes; unpaired tool calls are repaired before send; shell/MCP writes bust the file-read cache; 429/529 rate limits retry instead of dying.
- **Web search relevance (#898)** — Decoy Bing SERPs are filtered out; DuckDuckGo and Stack Overflow join the general engine set; optional `deep_read` for ranked excerpts.
- **Brain reindex (#855)** — Full workspace reindex completes on real repos; PageRank actually persists; the UI polls a background job instead of timing out.

## Install (Windows)

1. Download **Minnow-Setup-0.0.5.exe** from the [v0.0.5 release assets](https://github.com/HenriGrimm/Minnow/releases/tag/v0.0.5) (attached when the draft is published).
2. If SmartScreen warns about an unsigned build, choose **More info** → **Run anyway** (one-time for the first manual install).
3. On first launch, choose a workspace folder, then complete setup or connect a model from **Settings**.

## Install (Linux)

1. Download **Minnow-0.0.5-x86_64.AppImage** from the release assets.
2. Make it executable: `chmod +x Minnow-0.0.5-x86_64.AppImage`
3. Run it (AppImage; no system package manager required). Tray integration needs AppIndicator/StatusNotifier (common on KDE; GNOME may need an extension).

## Install (macOS)

1. Download **Minnow-0.0.5-arm64.dmg** or **Minnow-0.0.5-arm64.zip** from the release assets.
2. Open the app from Applications (or unzip and drag to Applications). Signed/notarized builds update in-app when a newer release is published.
3. Choose a workspace on first launch.

## Updates

Packaged installs check [GitHub Releases](https://github.com/HenriGrimm/Minnow/releases) for `latest.yml` (Windows), `latest-linux.yml` (Linux AppImage), or `latest-mac.yml` (macOS). Attach those feed files when publishing the release or in-app update checks will not see the new build. **Draft** releases are invisible to the updater — publish when all platform binaries and feed files are attached.

## Fixes and changes (since v0.0.4)

### Issues

- **Issues app v2 (#892)** — Schema stays disk `version` 2 with `schemaRevision` 3 so older readers do not wipe state.
- Capture from menubar, **Alt+C**, right-click (files, editor selection, commits, chat, terminal), and drag-and-drop onto the rail, list, or board.
- Saved views, grouping, manual rank, triage view, sub-issues, inline cell editing, and keyboard chrome.
- Description editor that keeps untouched markdown blocks byte-for-byte.
- Assign to an agent hands a one-task plan to Orchestrate; GitHub sync with timestamp/content conflict resolution (manual, no poller yet).
- Settings → Issues: type icons, taxonomy tables, project-key preview.

### Models and hosting

- **llama.cpp loads (#891)** — Auto mode uses `--fit on`, omits `-ngl`, and sizes `-c` to a 32k-preferred ladder capped by `trainCtx` instead of `ngl=999` / 125k context.
- Failed and crashed serves are visible (SSE + heartbeat), diagnosed (OOM, corrupt GGUF, bad template), and retryable.
- Downloads resume with `Range` / sha256; split GGUFs load from shard `00001`; multiple llama-server processes stay resident under LRU + 20 min TTL.
- Completions route to the matching serve `baseUrl`; local providers keep `min_p` / `top_k` / `repetition_penalty`.
- **Memory estimates (#854)** — VRAM from attention geometry (GGUF header → family table → heuristic), not parameter count. Sliding-window layers, partial offload, and logits-sized compute buffers are modelled.
- **Qwen3.8-27B (#878)** — Catalog Unsloth Q4_K_M, pin llama.cpp **b10448**, serve with `--jinja` and sibling `--mmproj`; composer High maps to wire `xhigh` + `preserve_thinking`.
- llama.cpp `/props` now reports live context window and vision for hosted models.
- GGUF metadata, launch timeouts, and Models page inspector layout (wider inspector, advanced accordion).
- Models runtime log fills the OS stage and scrolls instead of clipping at the window bottom (#882, MIN-606).

### Chat, composer, and Code

- **Compact composer** — Below 880px the row is mode dropdown, cog, model chip, context wheel; leave compact only above 920px. Cog sheet is a two-page portal (#915).
- Chat viewport dock keeps the jump chip and code-change strip from overlapping; Commit / Create PR sit beside undo.
- Code stage navigation is unified (chat, overview, map, Super Plan, Orchestrate, Dev servers) so competing overlays close cleanly.
- Right pane split keeps the file viewer visible when a preview tab stays open; preview guest stays painted beside Code stage views and re-syncs bounds.
- Composer spellcheck and auto-resize; paste of clipboard images no longer duplicates entries.
- Streaming assistant bubbles paint incrementally (~10/sec) instead of starving until the turn ends (#868).
- Super Plan composer grows with typed lines (#883).
- Drop folders from Explorer/Finder into the Code file tree (MIN-592, #886).

### Agents, thinking, and vision

- **Harness floor (#875)** — Parallel tool Stop no longer throws; unpaired `tool_calls` are repaired before send; `execute_command` / MCP / plugin writes invalidate the file-read cache; 408/425/429/529 retry with `Retry-After`.
- Thinking-budget cuts continue from the reasoning already produced and are scoped per turn, not per tool-loop iteration (#872).
- Vision probe for image-input support; Qwen `<tool_call>` / Harmony commentary parsed from local runtimes; screenshots feed vision models as image follow-ups (#871).
- LM Studio tok/s and TTFT trust server `stats` when usage-coherent; tool-loop tok/s is completion-weighted.
- `browser_screenshot` `capturePage` bounded at 3s so a hung capture cannot stall the tool loop.
- Orchestrate boards store and propagate **reasoning effort** and **thinking mode** to task/planner chats.

### Orchestrate, boards, and Super Plan

- AFK board chats recover after stall-stop instead of staying idle; live tool stdout counts as progress (#894).
- Orchestrator `git init` no longer loops on `ask_question` (MIN-615, #887).
- Git setup skill integration and orchestrate tool-management polish.
- Super Plan page layout and responsiveness.

### Tools, search, MCP, and LSP

- **Web search (#898)** — Relevance guard filters decoy SERPs; DuckDuckGo re-enabled; Stack Overflow in `general`; `safe_search: 1`; SearXNG `secret_key` no longer regenerates every launch; optional `deep_read`.
- MCP tool dispatch no longer mangles snake_case names; MCP tools appear in Settings → Tools with persistable permissions (#881).
- `read_file` on Excel/Office no longer dumps ZIP bytes (MIN-614, #884).
- TypeScript language server restarts when Vite/Node project inputs change (MIN-616, #885).

### Brain, research, and preview

- Brain full reindex streams usage scans, frames worker IPC, returns `202` + poll, surfaces `failedFiles`, and actually writes PageRank (#855).
- Research model handling and UI component cleanup.
- Preview execution timeouts (guest JS 30s); layout sync when Code stage views hide the chat rail.

### CI, packaging, and internals

- Capabilities matrix for model/host testing (#874) — Bench stays release-gated.
- Restore `@emnapi` optional lockfile entries so `npm ci` works on Windows.
- Issue v2 tools wired through fixtures, groups, and the capability catalog.
- Generation timeout / supervision threshold updates; benchmark timeout propagation.
- Product wiki catalog and bundle-budget refreshes after lockfile/CI drift.
