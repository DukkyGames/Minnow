# Minnow v0.1.0 — Open beta

Sixth open-beta build, and the first **0.1.x**. Focused on **Orchestrator V2**, **multi-window workspaces**, **session durability**, and a **shared agent runner** for chat, boards, and sub-agents. Feedback and bug reports are welcome on [GitHub Issues](https://github.com/HenriGrimm/Minnow/issues).

~196 commits since [v0.0.5](https://github.com/HenriGrimm/Minnow/releases/tag/v0.0.5) (21 Aug 2026 → 5 Sep 2026). Full diff: https://github.com/HenriGrimm/Minnow/compare/v0.0.5...v0.1.0

## Highlights

- **Orchestrator V2** — Live boards are an append-only journal under `~/.minnow/boards/` plus a renderer that never mutates board state. Intake is `parsePlan` (no planner LLM). Waves of Builder/Tester agents run in isolated git worktrees, merge through a queue, and recover from crash/reload by replaying the journal. Orchestrate opens `#/app/code/boards`, not a chat. V1 board tools were deleted (MIN-715); the shipped catalog is **105** tools.
- **One workspace per window** — Several folders can be open at once as separate Electron windows. A folder belongs to exactly one view. Close asks before tray/hide. The workspace gate is the welcome page (`#/workspaces`).
- **Sessions that survive restart** — Canonical store is `sessions/sessions.db` with rotating verified snapshots. Lazy history boot cannot wipe transcripts. Failed turns offer Continue / Clear. App open asks before resuming interrupted chats and boards (#953).
- **Shared runner** — Product chat, board attempts, and sub-agent runs share `server/runner`. Sub-agent journals live under `~/.minnow/agents/`. Context overflow summarizes and retries instead of hard-failing (#948, #950).
- **Chat and Code** — Queued follow-ups (#1032), durable tab-link chips (#1034), Material file-type icons (#1035), in-app Review PR, issue sparkles expander (#1033).

## Install (Windows)

1. Download **Minnow-Setup-0.1.0.exe** from the [v0.1.0 release assets](https://github.com/HenriGrimm/Minnow/releases/tag/v0.1.0) (attached when the draft is published).
2. If SmartScreen warns about an unsigned build, choose **More info** → **Run anyway** (one-time for the first manual install).
3. On first launch, choose a workspace folder, then complete setup or connect a model from **Settings**.

## Install (Linux)

1. Download **Minnow-0.1.0-x86_64.AppImage** from the release assets.
2. Make it executable: `chmod +x Minnow-0.1.0-x86_64.AppImage`
3. Run it (AppImage; no system package manager required). Tray integration needs AppIndicator/StatusNotifier (common on KDE; GNOME may need an extension).

## Install (macOS)

1. Download **Minnow-0.1.0-arm64.dmg** or **Minnow-0.1.0-arm64.zip** from the release assets.
2. Open the app from Applications (or unzip and drag to Applications). Signed/notarized builds update in-app when a newer release is published.
3. Choose a workspace on first launch.

## Updates

Packaged installs check [GitHub Releases](https://github.com/HenriGrimm/Minnow/releases) for `latest.yml` (Windows), `latest-linux.yml` (Linux AppImage), or `latest-mac.yml` (macOS). Attach those feed files when publishing the release or in-app update checks will not see the new build. **Draft** releases are invisible to the updater — publish when all platform binaries and feed files are attached.

## Fixes and changes (since v0.0.5)

### Orchestrator V2

- **Engine** — Journal store (append-only JSONL + atomic snapshots), pure `derive` / `plan` / policy table, REST + SSE (`/api/boards`), scripted effector, crash/restart recovery (P0–P1). V1 renderer engine, lifecycle-repair, planner LLM, and `board_*` tools deleted (MIN-713–MIN-718).
- **Boards surface** — V2 page beside then instead of V1: ask/start pane, live header (model chip, reasoning, concurrency, Start/Stop/Rerun), task-detail overlay, chat-shaped attempt threads (MIN-777), live activity patches without remounting the kanban.
- **Delivery** — Worktrees, merge queue, default concurrency 2; task-keyed slot ids; bulk orphan reclaim; git init as Start preflight (400 on failure, not a stuck board).
- **Autonomy** — Manual is Stopped + per-task start; sequential is Running at N=1; unattended is Running. Settings → Autopilot stores `defaultStatus` + `maxConcurrentTasks`.
- **Workspace scope** — Journals stay global on disk; list/start only for the current folder. Workspace switch confirm-and-stops running boards (timeout so a hung report writer cannot block).
- **Follow-up** — End-of-run report can start a General chat with a board-ref chip (no auto-send).
- **Plan intake** — YAML + wave markdown via `parsePlan`. Soft `Depends on` placeholders. **Repair** spawns `plan-repairer` on the same file.
- **Tester ladder** — Browser rung (P5) plus unattended overnight harness (P5-D). Shared runner for board workers and sub-agents (P8 / P10).
- **UX keepers** — Last-opened board memory; Orchestrate activity dot; skip plan picker when a path is already bound (#1027); display-wake poll no longer kills live task chats (#949); auto-fix worktree/branch names (#958); always-on finish report, drag UX, concurrency + hands-off (#941).

Merged PRs in this area: #941, #949, #958, #1027, plus direct Orchestrator-V2 landings on `main`.

### Workspaces and desktop shell

- One workspace per Electron window; folder set + geometry persist as window-state `version: 2`.
- Welcome page / `#/workspaces` picker: Sandbox pinned, recents of folders opened directly, Open folder / Create project.
- In-app close-workspace dialog; window-close action preference (ask / tray / quit).
- Boot resume gate asks before restarting interrupted generations and unfinished boards (#953).
- Hardware acceleration setting + IPC; animations park while hidden or during streams (P7 / MIN-727).
- `ResizeObserver loop` window errors ignored so they do not file Issues noise.

### Chat, context, and the shared runner

- **Queued follow-ups** paint in the transcript and on Local Server (#1032).
- **Tab chips** — drag editor and browser tabs onto chat as durable links (#1034).
- **Context** — overflow turns summarize (or extractive `dropMiddle` on llama.cpp / MLX) and retry; exhausted turns are failed with Continue / Clear, not a quiet `no_report` (#948, #950, #959).
- In-flight tool call stays visible across a chat switch (#944). Interleaved `think` tags stay off the visible reply (#957).
- Total tokens with per-message stats chips. Est. cost cells no longer overlap (#937).
- GLM-5.3 reasoning support. Default sampler `maxTokens` 32768; board/config 64000. Chat must pass sampler so the loop does not fall back to a 2048 cap.
- `issue_*` tools allowed in Plan and Super Plan (Planner work-agent allowlist included).
- Streaming UI: ticked motion, coalesced painter, tool-row chrome restored for mid-batch switch (P7 / P10).
- Configurable tool-result size limits. Report-tool nudges for boards and sub-agents.
- Super Plan: spec/plan tabs retry empty reads so they do not stick until reload (#962); no spurious `resumed` log on stage start (#1030). Expand prompt on Super Plan and Research composers.

### Sub-agents and Issues

- Sub-agents adopt the shared runner; journals under `~/.minnow/agents/`; HTTP `/api/agents/*`; reload/restart recovery (P8-H).
- Spawn cards re-anchor after `renderChatFromHistory`. Settings for sub-agent types and runtime validation.
- **Review PR** — `pr-reviewer` sub-agent from Issues and Source Control; results in `~/.minnow/reviews/state.json`.
- Issues **Expand** (sparkles) rewrites title + description into a review overlay; nothing saved until Apply (#1033).
- GitHub issue import no longer freezes the shell / empties the file tree (MIN-660, #961).
- Empty rule groups can be deleted in Settings → Rules (#1031).

### Code, git, and files

- Material Icon Theme colorful SVGs in the file tree and unified viewer tabs (#1035).
- Files / Browser / Source Control pane cluster with stable Files button (MIN-655).
- File-tree drag-and-drop move, including `dragend` fallback (#939).
- Word wrap for git commit review (#1029).
- Message ⋮ placement, sticky Super Plan pipeline column, wallpaper removal (MIN-733, MIN-735, MIN-652, #1037).
- Preview panel visibility: hide native guest while issue capture is open; stay painted beside Code stage views.

### Models, terminal, sandbox

- Vision capabilities probed on first model load (MIN-671, #960).
- MLX load and inference meters (MIN-587). Local Server loading progress.
- llama.cpp offload slots for `-ngl`; default reasoning options for openai-v1 (`reasoning_effort` into `chat_template_kwargs`).
- Terminal: zsh history no longer echoes `^A^K` (MIN-670, #956); clipboard paste; Ctrl+C copies selection; Windows process ancestor tracking.
- Dev servers: do not inject Vite `--port` into non-Vite CLIs.
- Landlock: path-list caps and compact home-read fallback so the helper does not exit 64.
- Appearance: Google Fonts catalog; only the selected UI + mono pair is fetched. Geist removed.

### Sessions, CI, packaging

- SQLite sessions store + PATCH dirty flushes; rotating `sessions-<ISO>.db` snapshots with `quick_check`; JSON mirror retired.
- History-omitting PUT/PATCH cannot wipe or resurrect empty chats; deletion is explicit `deleteChatIds` only.
- Code-change summaries skip unloaded chats (MIN-734).
- Fake-model Windows close: destroy sockets before `server.close`; CI flake fixes for MLX download reset.
- Product wiki catalog hash refresh (#1040). Bundle/wiki/capability matrix churn as generated artifacts.
