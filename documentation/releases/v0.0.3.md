# Minnow v0.0.3 — Open beta

Third open-beta build centered on a **workspace-first shell**, a **library-first Super Plan and Orchestrate** experience, and polish across **Brain**, **Models**, **Research**, and **agent safety**. Feedback and bug reports are welcome on [GitHub Issues](https://github.com/HenriGrimm/Minnow/issues).

## Highlights

- **Workspace-first boot** — Pick a workspace at launch; the app rail, boot loader, and Code surface align to that folder. Switching workspaces can start a fresh chat so context does not leak across repos (#825).
- **Super Plan library** — Plans live in a dedicated library surface with workspace-aware listing, delete from a context menu, and tighter integration with the workspace gate (#827).
- **Orchestrate hub and boards** — Redesigned hub/board shell (library rail + main pane), improved plan discovery and onboarding, board chats open inside Orchestrate (#830), and **Make a plan** routes to Super Plan (#832).
- **New slash skills** — `/plan-work` and `/orchestrate-plan` for phased plans and gated board execution; `/fix-ci` helps triage failing GitHub Actions (#824, #796).
- **Agent shell sandbox (opt-in)** — Settings → General → Agent shell sandbox (`off` / `prefer` / `require`) wraps one-shot agent terminal commands on macOS (Seatbelt) and Linux (Landlock); default remains off (MIN-553, #810).
- **Models and MLX** — Auto-load hosted models before chat completions, reconcile stale serves after restart, correct MLX context window and runtime logs, and cleaner MLX server shutdown (#809, MIN-562, MIN-565, MIN-552, #823).
- **Per-workspace Issues** — Issue project keys (MIN-n style) follow the active workspace (#783).
- **Desktop zoom** — Ctrl + scroll wheel zooms the shell UI in and out (#790).

## Install (Windows)

1. Download **Minnow-Setup-0.0.3.exe** from the [v0.0.3 release assets](https://github.com/HenriGrimm/Minnow/releases/tag/v0.0.3).
2. If SmartScreen warns about an unsigned build, choose **More info** → **Run anyway** (one-time for the first manual install).
3. On first launch, choose a workspace folder, then complete setup or connect a model from **Settings**.

## Install (Linux)

1. Download **Minnow-0.0.3-x86_64.AppImage** from the release assets.
2. Make it executable: `chmod +x Minnow-0.0.3-x86_64.AppImage`
3. Run it (AppImage; no system package manager required). Tray integration needs AppIndicator/StatusNotifier (common on KDE; GNOME may need an extension).

## Install (macOS)

1. Download **Minnow-0.0.3-arm64.dmg** or **Minnow-0.0.3-arm64.zip** from the release assets.
2. Open the app from Applications (or unzip and drag to Applications). Signed/notarized builds update in-app when a newer release is published.
3. Choose a workspace on first launch.

## Updates

Packaged installs check [GitHub Releases](https://github.com/HenriGrimm/Minnow/releases) for `latest.yml` (Windows), `latest-linux.yml` (Linux AppImage), or `latest-mac.yml` (macOS). Attach those feed files when publishing the release or in-app update checks will not see the new build. **Draft** releases are invisible to the updater — publish when binaries are attached.

## Fixes and changes (since v0.0.2)

### Shell, workspace, and boot

- **Workspace gate and app rail** — Workspace picker at cold boot; dual-gate loader waits for CSS and chrome before dismissing the splash; in-session workspace switch avoids re-running cold-boot reveal (#825).
- **Fresh chat on workspace switch** — Optional clean chat when changing workspace so prior thread context does not carry over.
- **App initialization** — Session and app-layer visibility fixes for reliable switching between Code, Brain, Orchestrate, and other apps.
- **Boot performance** — Graph eviction and streaming path optimizations reduce work during startup and long chats (#784).

### Super Plan and Orchestrate

- **Super Plan library-first UI** — List, open, and manage saved plans from a library rail; workspace-scoped plan storage (#827).
- **Orchestrate page shell** — Shared hub/board layout with plan discovery, tighter header telemetry, and board chats embedded in the Orchestrate screen (#830).
- **Routing** — Orchestrate hub **Make a plan** opens Super Plan instead of the wrong surface (#832).
- **Built-in skills** — `plan-work` (discovery + phased plans under `documentation/plans/`) and `orchestrate-plan` (implement → verify gates on a board) (#824).

### Brain, Research, and Scheduler

- **Brain workbench** — Layout and graph sidebar polish; note editing with split view and metadata toolbar.
- **AI wiki cleanup planner** — Brain-assisted planning for wiki maintenance (#831).
- **Research** — In-flight research activity persists across reload (#833).
- **Scheduler** — Revamped header and task editor styling.

### Code, terminal, and tools

- **Agent shell sandbox** — Opt-in sandbox for agent-driven one-shot shell commands; Windows clamps `require` to `prefer` (MIN-553, #810).
- **Terminal runs** — Track agent terminal runs across eviction and host restarts (MIN-559, #799).
- **Grep tool** — Stable sort by path for predictable pagination.
- **GitHub in agent chats** — System prompt guidance to use local `gh` CLI for PRs/issues/CI instead of scraping github.com (MIN-558, #794).

### Models and hosting

- **My Models** — Auto-load hosted models before sending chat completions (#809).
- **Serve reconciliation** — Drop stale serve records after Minnow restart (MIN-562, #806).
- **MLX** — Context wheel reads `config.json` context length (MIN-565, #807); Models app runtime log fix (MIN-552, #803); improved MLX process shutdown (#823).
- **Custom GPU layers** — Hosting respects custom layer counts (MIN-551, #795).

### Chat and UI

- **Stop vs steer** — Enter stops generation instead of sending a queued steer message (MIN-557, #805).
- **Live metrics** — Clearer token and throughput display in the stats strip.
- **Chat layout** — Bubble and message action width fixes.
- **Windows** — **Open in System Explorer** opens the correct path (MIN-543, #797).
- **Theme** — Legacy success color tokens repaired for consistent status styling.

### Issues

- **Per-workspace keys** — Issue prefixes and project scope follow the active workspace root (#783).

### Documentation and CI

- Manual, `context.md`, and agent docs updated for workspace-first navigation and app rail (#825 follow-up).
- Headless CLI smoke coverage folded into the main CI workflow; redundant headless workflow removed.
- Sandbox, worktree, and server-reaper fixes for Linux CI and WSL `/tmp` argv on Windows/macOS orphan matching.
