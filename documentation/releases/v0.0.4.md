# Minnow v0.0.4 — Open beta

Fourth open-beta build focused on **Orchestrate and board execution**, **model routing and hosting polish**, **Brain code index**, **memory editing**, and **human-readable Super Plan / Research names**. Feedback and bug reports are welcome on [GitHub Issues](https://github.com/HenriGrimm/Minnow/issues).

## Highlights

- **Orchestrate and boards** — Refined hub/board shell, synthesis configuration, board chat metrics, board view improvements, and task worktree synchronization so parallel board work stays aligned with git worktrees.
- **Model routing** — Optional **prompt expander** model binding in Settings → Model routing (expands short user prompts before the main chat model when configured).
- **Models picker** — Streamlined **Load / Unload** for local and My Models rows; host filter bar wired through load/unload resolvers; improved provider resolution and request handling.
- **MLX hosting (MIN-572)** — Ensures the Hugging Face hub cache directory exists before spawning `mlx-lm`, fixing first-run local server failures (#836).
- **Super Plan and Research naming (#838)** — Plan artifacts under `documentation/plans/` rename from the **build spec / plan title** (not the raw opening prompt). Research library rows show **report titles** with server-side persist and backfill.
- **Brain code index** — Stronger `/api/brain/code/*` behavior and Code app integration for workspace-scoped indexing and maps.
- **Memory** — Edit saved memory entries from the Memory UI with clearer management flows.
- **Product wiki** — Preview guest hides correctly when the in-app manual overlay is open; catalog generation and CI guardrails for shipped documentation.
- **Preview and sharing** — Screenshot links can include session token support for authorized capture flows; improved guest error handling for user code in preview.
- **Chat reliability** — Clearer generation error reporting; agent activity streamlining and stop-generation behavior; composer draft and sidebar update optimizations.

## Install (Windows)

1. Download **Minnow-Setup-0.0.4.exe** from the [v0.0.4 release assets](https://github.com/HenriGrimm/Minnow/releases/tag/v0.0.4).
2. If SmartScreen warns about an unsigned build, choose **More info** → **Run anyway** (one-time for the first manual install).
3. On first launch, choose a workspace folder, then complete setup or connect a model from **Settings**.

## Install (Linux)

1. Download **Minnow-0.0.4-x86_64.AppImage** from the release assets.
2. Make it executable: `chmod +x Minnow-0.0.4-x86_64.AppImage`
3. Run it (AppImage; no system package manager required). Tray integration needs AppIndicator/StatusNotifier (common on KDE; GNOME may need an extension).

## Install (macOS)

1. Download **Minnow-0.0.4-arm64.dmg** or **Minnow-0.0.4-arm64.zip** from the release assets.
2. Open the app from Applications (or unzip and drag to Applications). Signed/notarized builds update in-app when a newer release is published.
3. Choose a workspace on first launch.

## Updates

Packaged installs check [GitHub Releases](https://github.com/HenriGrimm/Minnow/releases) for `latest.yml` (Windows), `latest-linux.yml` (Linux AppImage), or `latest-mac.yml` (macOS). Attach those feed files when publishing the release or in-app update checks will not see the new build. **Draft** releases are invisible to the updater — publish when all platform binaries and feed files are attached.

## Fixes and changes (since v0.0.3)

### Orchestrate, boards, and Super Plan

- Board chat embedded in Orchestrate with synthesis configuration and header metrics.
- Board view and task list improvements; worktree sync when board tasks use isolated worktrees.
- Hub and board chat routing polish.
- **Plan and brief naming (#838)** — Slugs and on-disk filenames derived from build spec / plan titles; research library displays report titles.

### Models and hosting

- **Prompt expander** — Dedicated model routing slot for prompt expansion (`config.json` + Settings UI).
- Composer and picker **host filter** load/unload actions call the correct resolver (local serves vs library).
- Model request handling and active provider resolution improvements.
- **MIN-572** — Create HF hub cache before MLX spawn (#836).
- Dependency and session-mirroring updates for hosted model state.

### Brain, memory, and research

- Brain code indexing API and UI pass enhancements for workspace roots.
- Memory entry **edit** support and UI polish.
- Research titles persisted for library display (#838).

### Shell, preview, and wiki

- Preview `WebContentsView` visibility respects product wiki overlay and other chrome (no click-through dead zones).
- Product wiki catalog sync in CI; performance budget alignment for eager JS.
- Screenshot link helper with optional session token.
- Preview guest errors surfaced more clearly for user-run code.

### Chat and agents

- Agent activity management and stop-generation logic streamlined.
- Chat generation failures reported with clearer user-facing errors.
- Composer draft persistence and sidebar refresh optimizations.

### CI and packaging

- CI stall recovery and model picker CSS contract fixes.
- Restore `@emnapi` optional dependencies in `package-lock.json` for Windows native paths.
- Merge-fixer finalize guard under parallel tests.

```bash
cd Minnow
git checkout v0.0.4
npm install
npm start
```
