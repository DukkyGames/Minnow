# Minnow manual

Minnow is a free, local-first AI workspace on your own computer. You chat with models you already run (LM Studio, Ollama, or any OpenAI-compatible endpoint), edit code beside the assistant, research the web, remember facts in Brain, and tune everything from Settings. Your chats, keys, and files stay on your disk unless you send traffic to a provider you configured.

This manual is written for the **packaged desktop app** (installer from GitHub Releases). Developers who build from source should use the [GitHub Wiki](https://github.com/DukkyGames/Minnow/wiki) or [`documentation/contributor/setup-from-source.md`](../contributor/setup-from-source.md) in the repository (not shown in the in-app wiki).

## Get help inside Minnow

Open the official **Minnow wiki** from the menubar **?** button. Browse sections, search titles and page text, and use **Ctrl+K** or **Cmd+K** while the wiki is open to focus search. The wiki is read-only and matches your installed version.

Desktop chat in **General** mode can also search official docs with read-only tools (`minnow_docs_search`, `minnow_docs_read`, `minnow_docs_list`). Ask how to set up providers, modes, or apps and the assistant can cite wiki pages.

**Brain** is separate: your editable knowledge wiki at home in the Brain app. See [Wiki and Brain](reference/wiki-and-brain.md).
